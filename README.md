# Анализ резюме из HeadHunter

## Описание проекта

Проект выполнен в рамках обучения в МИФИ и SkillFactory.

Цель проекта — исследовать данные резюме HeadHunter, выявить зависимости между признаками и подготовить данные для дальнейшего анализа.

## Этапы работы

1. Исследование структуры данных.
2. Преобразование признаков.
3. Разведывательный анализ и визуализация данных.
4. Очистка данных от дубликатов, пропусков и выбросов.

## Используемые библиотеки

- Pandas
- NumPy
- Matplotlib
- Seaborn
